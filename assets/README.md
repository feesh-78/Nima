# 🎥 Vidéo de fond, page « Partie 2 » (escapade au bord du lac)

Déposez ici votre **vidéo libre de droit** pour qu'elle s'affiche en fond plein écran :

- `lac.mp4`, la vidéo (obligatoire)
- `lac.jpg`, une image « poster » affichée le temps que la vidéo charge (optionnel, recommandé)

La page `partie2.html` les utilise automatiquement. Tant que `lac.mp4` n'est pas
présent, un **magnifique fond animé de secours** (lac au crépuscule + reflets) s'affiche.

## Conseils pour la vidéo
- Format **MP4 (H.264)**, orientation **paysage**, idéalement **1080p**
- **Sans son** (la page la lit en muet, en boucle)
- Sujet : **maison / cabane au bord d'un lac avec grande baie vitrée**, eau calme,
  lumière douce (aube ou crépuscule)
- Poids conseillé : **< 20 Mo** pour un chargement rapide sur mobile
  *(si votre vidéo est lourde, on peut la raccourcir / compresser)*

## Où trouver des vidéos libres de droit
- **Pexels** (pexels.com/videos) · **Coverr** (coverr.co) · **Pixabay** (pixabay.com/videos)
- Recherches utiles : « lake house window », « lakeside cabin », « calm lake sunrise »,
  « cabin lake view »

## Comment la mettre en place
1. Renommez votre fichier en `lac.mp4` (et éventuellement une image en `lac.jpg`)
2. Placez-le dans ce dossier `assets/`
3. Poussez sur GitHub (ou envoyez-le moi et je m'en occupe)

C'est tout, la vidéo apparaîtra en fond de `partie2.html`. ✨
